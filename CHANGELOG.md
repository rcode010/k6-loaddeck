# Changelog

## 0.1.0 development preview

- Add URL-first testing with real local Grafana k6 execution and cancellation.
- Add live metrics, final summaries, persistent history and compatible-run comparison.
- Add multi-scenario workloads, six executor forms, checks and scoped thresholds.
- Add HTTP/2 negotiation, WebSocket and unary gRPC generation, protected authentication references and JSON/CSV data bindings.
- Add concurrent native outputs, normalized exports and explicit external-output adapters for the verified binary profile.

- Add status lists, regex/header/UTF-8 checks, check groups/tags, scenario filters and real scoped outcomes.
- Add metric-aware threshold controls, decimal percentiles, delayed-abort verification, incomplete observations and unevaluated results.
- Add scoped comparison and common chart scales, preserve exact bucket widths and show native protocol comparison metrics.
- Preserve special JSON/header/tag/check keys, distinguish silent versus empty responses and enforce a total UTF-8 log limit.

This preview has not passed every stable 1.0 acceptance criterion. See `docs/READINESS.md`.
